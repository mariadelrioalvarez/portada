## Descripción
Mi Portfolio es una página web personal desarrollada como proyecto de TIC II. Su objetivo es mostrar mis trabajos a lo largo del curso y poner en práctica los conocimientos adquiridos sobre desarrollo web.

## Tecnologías y herramientas utilizadas
- HTML
- CSS
- Bootstrap
- Visual Studio Code
- Git y GitHub
- FileZilla
- ChatGPT (como herramienta de apoyo durante el desarrollo)
